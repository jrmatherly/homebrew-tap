# homebrew-tap

Homebrew formulae for [jrmatherly](https://github.com/jrmatherly)'s tools.

```sh
brew install jrmatherly/tap/claude-multipass
```

| Formula | What it installs |
| --- | --- |
| `claude-multipass` | Switch Claude Desktop between claude.ai accounts without an email code ([repo](https://github.com/jrmatherly/claude-multipass)) |
